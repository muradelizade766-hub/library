# Library Management System

## Project Description
A desktop-based Library Management System built with Python and Tkinter. This application allows users to manage books, register members, handle borrowing and returning processes, and persist data using structured files.

## Features
- Add, remove, and search books
- Register new library members
- Borrow and return books with validation checks
- Persistent data storage
- Graphical User Interface (GUI) built with Tkinter
- Automated unit testing with `unittest`

## Technologies Used
- Python 3
- Tkinter (GUI)
- Git & GitHub (Version Control)
- Unittest (Testing Framework)
